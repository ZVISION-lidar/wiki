# Odin1

> 空间记忆模组 · 全球首款深度融合 LiDAR + 视觉 + SLAM 算法的产品

## 产品亮点

| 维度 | 详细规格 |
|:---|:---|
| **超高性能空间感知** | 70m（90% 反射率）/ 30m（10% 反射率）超远测距 · 120°×90° 超广视场角 · 最高 70 万点/秒高密度点云 · 彩色全局曝光 |
| **超鲁棒空间记忆** | ±5cm+1% 厘米级全局定位 · 最高 400Hz 高频位姿更新 · 暗光/玻璃/水面等复杂环境自适应 |
| **小巧全能工业设计** | 约 280g 超轻重量 · 100×62×43mm 紧凑尺寸 · IP66 防尘防水 · 12-24V 宽电压适配 · 抗冲击（高达 32G） |
